# .github

Defaults for every Sayer-Strategy-Group repo that has no file of the same type:

- `PULL_REQUEST_TEMPLATE.md`: the pull request description the Sayer kit writes. The Linear issue line, the check result, what changed, decisions for the assignee to confirm, the review, and steps after merge.
- `.github/ISSUE_TEMPLATE/config.yml`: points people to Linear, where Sayer tracks work. Blank GitHub issues stay on for repos that still use them.

GitHub applies these defaults only while this repo is public, so it stays public and holds nothing private. A repo replaces a default by adding its own file of that type.
